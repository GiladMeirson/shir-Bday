# יום הולדת שיר 🎁 — מכונת המתנות

אתר סטטי (ללא build): פתיח + ברכה → משחק Claw Machine → 4 מתנות בזו אחר זו, האחרונה אמיתית (תאילנד) עם כרטיסי טיסה וקונפטי.

## איך מריצים

פשוט לפתוח את `index.html` בדפדפן (עובד גם מ־file://). עדיף על טלפון / Chrome.
כדי לשתף — לעלות את התיקייה כמו שהיא ל־GitHub Pages / Netlify / כל אחסון סטטי.

## מה צריך להשלים (PLACEHOLDERS)

הכל בקובץ **`js/app.js`**, בבלוק `CONFIG` שבראש הקובץ:

| שדה | מה לכתוב |
|---|---|
| `greeting` | הברכה האישית לשיר (כמה שורות; שורה ריקה = פסקה) |
| `gifts[3].flights.passengers` | `['שיר', 'גלעד', '[שם הילדה]']` — להחליף את שם הילדה |
| `gifts[3].flights.out` / `back` | תאריכים, שעות, ויעד (`BKK` בנגקוק / `HKT` פוקט וכו') |
| `gifts[3].flights.hotel`, `nights` | שם המלון/האי ומספר לילות |
| `gifts[3].finalNote` | השורה המסכמת מתחת לכרטיסים (HTML מותר) |
| `gifts[*].sub` / `kicker` | טקסטי ההומור לכל מתנה — אפשר לערוך חופשי |
| `roundSeconds` | זמן לכל ניסיון במכונה (ברירת מחדל 30) |

התמונות נטענות מ־`assets/` (הנתיבים כבר מוגדרים ב־`gifts[*].img`).

## תצוגה מקדימה מהירה

- `index.html?screen=game` — ישר למכונה
- `index.html?gift=0` … `?gift=3` — מסך המתנה הארוזה של מתנה מס׳ N
- `index.html?gift=3&open=1` — הכרטיס הפתוח (למתנה 3 = תאילנד, עם הקונפטי)

## מבנה

```
index.html          מסכים (פתיח / משחק / חשיפה)
css/style.css       עיצוב
js/app.js           CONFIG, זרימת המסכים, סאונד, קונפטי
js/claw.js          המשחק: פיזיקה + רינדור
js/engine.js        מנוע פיזיקה (נוצר אוטומטית מ־.claude/skills/physics-2d)
js/atelier.js       Shading/Easing/Noise (נוצר אוטומטית מ־.claude/skills/canvas-atelier)
tools/bundle.js     node tools/bundle.js — מייצר מחדש את engine.js / atelier.js
tools/shot.html     harness לצילומי מסך/סימולציה דטרמיניסטית (?x=250&t=6&seed=3)
tools/mobile.html   מסגרת 390px לבדיקה כמו טלפון
```

## איך המשחק "עובד עליה"

- 9 מתנות בצבעים שונים — הסדר של המתנות שנחשפות **קבוע** ולא תלוי בצבע שנתפס.
- אחיזה חלשה (לא במרכז / קופסה נטויה) נשמטת בדרך; מתנה שמשתחררת עם תנופה יכולה לנחות על שפת הפתח ולחזור לערימה.
- אחרי 2 כישלונות רצופים המכונה "מרחמת" ומקטינה את הסיכוי להישמט (ואחרי 4 — עוד יותר), כדי שלא תיתקע.
